# פנייה למועמדים

דף סטטי (קובץ `index.html` אחד) לפנייה למועמדים בוואטסאפ או בחיוג, עם הודעות מוכנות.

- **מסך מנהל** (הכתובת הרגילה): מגדירים אחראים ונוסחי הודעות, מעלים קובץ CSV/Excel, משייכים מועמדים לאחראים ושולחים לכל אחראי קישור אישי.
- **מסך אחראי** (קישור עם `#d=`): הרשימה של האחראי, כפתורי וואטסאפ וחיוג, וסימון סטטוס.

אין שרת. הנתונים נשמרים בדפדפן (localStorage) ובתוך הקישורים האישיים, ולא נשמרים בריפו.
